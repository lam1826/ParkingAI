Promt: 
Bạn là Software Architect có hơn 15 năm kinh nghiệm.

Tôi đang phát triển đồ án:

"Hệ thống quản lý bãi đỗ xe tích hợp AI"

Công nghệ:

- Backend: FastAPI
- Frontend: React
- Database: SQLite
- ORM: SQLAlchemy 2.x
- AI: Gemini

Các chức năng:

1. Đăng nhập
2. Phân quyền
3. Quản lý khu vực
4. Quản lý vị trí đỗ
5. Quản lý loại xe
6. Xe vào
7. Xe ra
8. Vé gửi xe
9. Vé tháng
10. Khách quen
11. Bảng giá
12. Tính phí
13. Theo dõi chỗ trống
14. Thống kê doanh thu
15. Thống kê lưu lượng
16. AI sinh báo cáo
17. AI trả lời câu hỏi quản trị

Yêu cầu:

1. Thiết kế CSDL chuẩn hóa đến 3NF.
2. Liệt kê tất cả các bảng.
3. Mỗi bảng gồm:
   - Tên bảng
   - Các trường
   - Kiểu dữ liệu
   - Primary Key
   - Foreign Key
4. Mô tả quan hệ giữa các bảng.
5. Sinh sơ đồ ERD bằng Mermaid.
6. Giải thích ngắn gọn lý do thiết kế.
Không viết code SQL, chỉ thiết kế.
